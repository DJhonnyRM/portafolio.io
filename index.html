Proyectos destacados

Bug Bounty · HackerOne
Bug Bounty — Reportes en HackerOne · Web · API · Mobile · Web3

Investigación activa con varios reportes enviados en HackerOne (severidades High y Medium) sobre apps Android, APIs y superficies web, cloud y Web3. Flujo completo: recon y mapeo de assets, reversing de APKs (jadx) y análisis dinámico (Frida, MobSF), explotación y redacción de PoC bajo metodología OWASP. Hallazgos anonimizados (programas no divulgados):

  • High Business logic — forgery de visitas de afiliado por parámetro aceptado sin validación
  • Med IDOR / BOLA horizontal en API multi-tenant — acceso a datos de otros usuarios
  • Med Interceptación de Authorization Code vía custom URI scheme (OAuth / SSO / WebAuthn)
  • Med Deeplink exportado carga URL/JS controlado por el atacante en WebView (Android)
  • Med Bucket S3 sin autenticación expone PKI / almacén de secretos de producción
  • Med Bypass de validación de rango en endpoint RPC de blockchain (Web3)
  • Med Falta de rate limiting en envío de OTP — SMS/voz/WhatsApp bombing y toll fraud
  • Med Information disclosure — env.json, API keys y errores verbosos con internals

Sysadmin · Infraestructura
Datacenter On-Premise — Proyecto Final Sistemas Operativos II

Diseño e implementación de un datacenter on-premise completo para una empresa simulada, montado en VirtualBox con red entre hosts (switch/router) e integrando servicios Windows y Linux con hardening en cada capa. Servicios desplegados: Windows Server 2022 (Active Directory, DNS, WSUS) y hardening por GPO sobre clientes Windows 11 —bloqueo de CMD/PowerShell/regedit/Panel de control, screen-lock y folder redirection—; servidor LEMP con Laravel para señalización digital; Samba (CentOS) con permisos por áreas; SFTP (OpenSSH + UFW); NOC con Zabbix y dashboard centralizado de CPU/memoria; y nube privada Nextcloud. Bastionado transversal: firewall, bloqueo de root por SSH y políticas de seguridad.
